V5 Premium Refresh — GitHub Pages-এ আপডেটের নিয়ম

গুরুত্বপূর্ণ: ZIP ফাইলটি GitHub-এ শুধু আপলোড করলে ওয়েবসাইট বদলাবে না। ZIP আগে iPhone Files অ্যাপে Extract করতে হবে। এরপর Extract হওয়া ফোল্ডার থেকে এই ৫টি ফাইল GitHub repository-র Pages publish করা একই ফোল্ডারে Upload করে পুরোনো ফাইল Replace করুন:
- index.html
- manifest.json
- sw.js
- trust-logo.png
তারপর Commit changes দিন এবং Pages deploy শেষ হওয়া পর্যন্ত অপেক্ষা করুন।

iPhone-এ পুরোনো Home Screen shortcut বন্ধ করে Safari-তে GitHub Pages ওয়েবসাইট খুলুন, Reload করুন। পুরোনো shortcut cache ধরে রাখলে সেটি মুছে নতুন করে Share > Add to Home Screen করুন।

সীমাবদ্ধতা: এটি এখনো প্রোটোটাইপ। ডেটা স্থানীয় ব্রাউজারে থাকে। Cloud sync, secure login/roles, encryption, QR card/camera scan এবং multi-phone duplicate lock এখনো তৈরি হয়নি। বাস্তব NID বা ব্যক্তিগত তথ্য দেবেন না।
